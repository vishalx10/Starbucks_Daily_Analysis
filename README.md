# ☕ Starbucks Store Sales Analysis Dashboard

## 📌 Project Overview

This project analyzes the daily sales data of a Starbucks store using SQL and Power BI. The goal is to understand sales performance, customer behavior, and product trends at a store level to support data-driven decision-making.

---

## 🎯 Objectives

* Analyze daily and hourly sales trends
* Identify top-performing products and categories
* Understand customer purchasing behavior
* Track revenue patterns at store level

---

## 🗄 Dataset Description

The analysis is based on three tables:

* **Sales** → Daily transaction data (date, quantity, revenue)
* **Customers** → Customer details
* **Items** → Product and category information

---

## 🛠 Tools & Technologies

* SQL (Data extraction, joins, aggregation)
* Power BI (Data visualization & dashboard)

---

## 📊 Key Analysis

* Daily sales performance
* Hourly sales trends (peak hours identification)
* Category-wise revenue analysis
* Customer purchase behavior
* Product performance tracking

---

## 📈 Dashboard Features

* Interactive visuals for sales trends
* Time-based analysis (daily & hourly)
* Clean and user-friendly design
